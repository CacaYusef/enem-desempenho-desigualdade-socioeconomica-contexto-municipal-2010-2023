# Análises

Use as subpastas conforme o propósito:

- `exploratory/`: inspeção de qualidade, distribuição e hipóteses preliminares;
- `descriptive/`: estimativas descritivas definidas;
- `inferential/`: testes e intervalos com hipóteses e premissas registradas;
- `models/`: especificações, diagnósticos e análises de sensibilidade.

Arquivos aqui devem orquestrar funções de `src/enem_analysis/` e registrar
entradas e saídas. A etapa inferencial não começa antes da formalização de
`docs/methodology.md`.
